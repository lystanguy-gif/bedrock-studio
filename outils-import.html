Import du contenu initial (les 19 toiles)

Outil de mise en place réservé au développeur. Il importe une seule fois les 19 toiles fournies (images + métadonnées de contenu-initial.json) dans Supabase : chaque image est envoyée dans le stockage, puis l'œuvre est créée dans la base.

Pré-requis : assets/config.js renseigné, schéma SQL exécuté, bucket paintings créé, et utilisateur de Léa créé. Connectez-vous ci-dessous.
