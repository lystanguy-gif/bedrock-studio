Importer des réservations

Collez un export CSV (colonnes nom, telephone, email, personnes, date, depart, message — c'est exactement le format exporté par les formulaires Netlify) ou un fichier CSV/JSON. Les doublons (même nom + date) sont ignorés.

Évolution : plateforme serveur sécurisée

Cette console fonctionne sans serveur, sur l'appareil. Pour une solution « hyper pro » multi-postes, voici l'étape suivante recommandée :

  • Réception automatique : le formulaire du site écrit directement dans une base de données (les demandes arrivent ici sans import).
  • Accès protégé : connexion par mot de passe / double authentification, plusieurs comptes équipage.
  • Paiement relié : statut « payé » mis à jour automatiquement par Stripe (webhook), reçus PDF.
  • Hébergement : Supabase / Firebase / petit serveur Node — chiffré (HTTPS), conforme RGPD, sauvegardes automatiques.
  • E-mails automatiques : confirmation envoyée toute seule, rappel la veille du départ.

Les données déjà saisies ici s'exportent en CSV/Excel et se réimportent dans la future plateforme — rien n'est perdu.
